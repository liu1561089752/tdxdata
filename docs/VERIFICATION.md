# 数据可信度说明

> 这是一份**给你核对用的技术附录**。README 讲怎么用，本文讲「这些数字为什么可信」。
> 不看也不会影响使用。

---

## 1. 四条原则

| 原则 | 具体做法 |
|---|---|
| **不猜** | 服务端没给列名的字段，不编英文名，只用 `c3` / `f4` 这种位置名 |
| **拿不到给 `None`** | 绝不用 `0` 冒充"没有数据"（`vol=0.0` 曾经就是这么埋坑的） |
| **派生值不当真值** | 算出来的东西不伪造成原始数据（例：指数分钟线的 `vol`） |
| **每个结论要能对上两条通道** | 一条通道算出来的，必须能被另一条独立算出来 |

第 4 条是这个库最核心的质检手段。下面所有"已验证"都指**至少两条通道互相对上**。

---

## 2. 数据从哪来

`tdxdata` 直连通达信的公开行情服务器（TCP 7615），**不需要安装任何客户端、不需要账号、不需要 API Key**。

- 一条连接同时服务两类数据：**行情**（K 线 / 分时 / 逐笔 / 报价）与**数据中心**（421 个产品）
- 库自己管理连接复用、节流、断线重连
- 所有返回都是明文解析后的结构，不落地任何中间文件

> 具体命令名、编号、帧格式属于实现细节，库已封装；只有用 `Client.call()` 直连底层时才需要关心，
> 详见 §7。

## 3. 单位是怎么定的

`vol` 的原始单位随**品种 × 周期**变，这是最容易差 100 倍的地方。判定方法只有一个：
**用同一条记录内部的恒等式反推**，不靠猜、不用启发式。

```
金额 / 成交量              ≈ 收盘价   → 单位是「股」
金额 / (成交量 × 100)      ≈ 收盘价   → 单位是「手」
可转债：金额 / 成交量 / 收盘价 ≈ 10    → 1 手 = 10 张
逆回购：金额 / 成交量       = 1000.0   → 1 手 = 1000 元
```

**为什么不用"像不像收盘价"这种自动判断？**
指数和板块的"价格"是点位，与成交额没有价格关系，自动判断必然误判。所以库内用**代码段白名单**
显式分类（见 `client._vol_kind`），不猜。

### 两个特殊结论

**① 周线 / 月线的成交量，服务端统一除以了 100，与品种无关**

拿周线 `vol` 与"当周每日日线之和"比，五个品类全部是 `vol 比值 0.010 / amount 比值 1.000`。
对股票正好变成"手"，对本来就是手计价的品种（转债/回购/指数/板块）就变成"手/100"，
所以库对后者**乘回 100**。

**② 指数 / 板块的分钟线 `vol` 不是成交量**

```
999999 60m：vol = 2,865,168,384   amount = 286,516,871,168   amount/vol = 100.000（整数）
2,865,168,384 手 = 2.86 万亿股 / 单小时 —— 不可能
```

`amount/vol` 恰好等于 100，说明 `vol` 就是 `amount/100` 算出来的**派生值**。
库返回 `None`，原值仍在 `raw["Volume"]`。**该品类的日线 `vol` 是真值**，照常返回。

## 4. 未定字段清单（知道为什么不敢定）

这些字段库**只给位置名**（`c3`/`f4`/`N001`），原值完整保留在 `raw` 里。

| 位置 | 现象 | 为什么不给它编名字 |
|---|---|---|
| 块数据 `c3` 起 | 第 4 列起是价格量额类 | 疑似 现价/昨收/涨跌额/成交额，但顺序无法互证 |
| 抽样 `f1..fN` | **个数会变**（实测 9→11→13→15），`f0`=开盘 | 列序没有锚点，只有 `f0` 能对上；声明 60 与实际不符 |
| 板块统计 `Other` 列 | 量纲**随参数变化** | 同一列在不同视图下含义不同，无法归一 |
| 逐笔 `InOutFlag` | 值 `0` / `1` | 不知道哪个是买、哪个是卖 |
| 逐笔 `HKTTFlag` / `HKInOutFlag` | `0` / `\x01` | 疑与港股通有关，未证实 |
| 逐笔 `VolInStockDiff` | 多数等于本笔量 | 疑似"与上一笔的量差"，无强证据 |
| 数据中心 `N001…` | 服务端不返回中文表头 | 列名映射见 `docs/` 与产品自带说明 |

> 判断"能不能定名"的三个自检：
> ① 能不能被第二条通道证实？② 换个参数它会不会变？③ 它是真的还是派生的？
> 有一条过不去，就只能进 `raw`。

## 5. 交叉验算模板（你可以自己跑）

```python
import tdxdata

with tdxdata.Client() as c:
    bars = c.get_bars("600519", "day", 5)              # 日线
    q    = c.get_quotes(["600519"])[0]                 # 报价
    mins = c.get_minutes("600519")                     # 当日分时

    # ① 日线单位：金额 /(量×100) / 收盘 ≈ 1
    b = bars[-1]
    print(b.amount / (b.vol * 100) / b.close)          # ≈ 1.000

    # ② 报价与日线同单位：两者 vol 直接可比
    print(q.vol, b.vol)                                # 同一量级

    # ③ 分时 240 点合计 ≈ 当日总成交量
    print(sum(m.vol for m in mins), b.vol)             # 比值 ≈ 1.0

    # ④ 逐笔只是当日的一小段，远小于总量
    t = c.get_ticks("600519", count=100)
    print(sum(x.vol for x in t), b.vol)                # 比值远小于 1
```

四条都对上，说明「单位 / 口径 / 时间对齐」三件事同时成立。

**其它可复现的核对点**

| 核对 | 方法 | 期望 |
|---|---|---|
| 指数点位 | `get_bars("999999")[-1].close` 对比行情软件 | 同一数量级 |
| 板块代码族 | `get_bars("881007")` / `get_bars("880903")` | 都能取到（同属沪市板块指数） |
| 市场码推断 | `get_quotes(["900901","113054","204001","920207"])` | 沪B/沪转债/沪回购/北交所都能取 |
| 复权 | `Adjust.NONE` 与 `Adjust.QFQ` 最新一根 | 相同（历史才分叉） |

## 6. 已知口径差异（不是 bug）

| 项 | 说明 |
|---|---|
| 涨跌停家数 | **含北交所**（如 59 家）；不含是 55 家（与东方财富涨停池一致）。用前先确认口径 |
| 资金流净值 | 与东方财富"主力净额"算法不同，**不宜跨源比较** |
| 后复权绝对值 | 各软件基准不同，本库与通达信客户端一致；与东财差一个恒定倍数 |
| 分页枚举 | `PBMultiHQ` 按涨幅排序，盘中会漂移 —— **保证不重复，不保证不遗漏** |
| 板块统计 | 返回哪个板块由服务端决定（请求里没有板块代码），要指定板块请用 `get_board_members` |

## 7. 底层命令（仅 `Client.call()` 需要）

`call(cmd, ctl, params)` 允许直调底层命令。已封装的方法对应关系：

| 方法 | 底层命令 |
|---|---|
| `get_bars` / `get_minutes` | `HQServ.PBFXT` / `HQServ.PBZST` |
| `get_quotes` / `get_name` | `HQServ.PBCombHQ` / `HQServ.PBHQInfo` |
| `get_market_page` / `get_universe` | `HQServ.PBMultiHQ` |
| `get_ticks` | `HQServ.PBTickEx` |
| `get_block_data` / `get_block_rows` | `HQServ.PBXmlBlock` |
| `get_samples` | `HQServ.PBSampleMore` |
| `get_board_stat` | `HQServ.PBHYStat` |
| `get(产品名)` | `CWServ.*` / `DataAggregation.*`（421 个产品） |

`ctl` 是服务端的分发编号：**填错不会报错，只会回空包**。所以 `call()` 返回空表时，
先怀疑 `cmd` 与 `ctl` 不匹配，而不是"没有数据"。

> `HQServ.*` 直接传裸参数；`CWServ.*` / `JJSServ.*` / `DataAggregation.*` 要包一层
> `{"Params": …}`。
